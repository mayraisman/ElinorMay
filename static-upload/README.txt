חבילת העלאה עצמית - מכינים את העסק לחגים

מה להעלות:
1. העלה את כל תוכן התיקייה הזו לשרת/אחסון שלך.
2. index.html חייב להישאר ליד styles.css.
3. תיקיית assets חייבת להישאר באותו מקום.

לפני פרסום:
1. פתח את index.html.
2. החלף את כל המופעים של href="#payment" בקישור התשלום האמיתי.
3. אם יש URL ציבורי קבוע, אפשר להוסיף canonical ו-og:url בתוך ה-head.

החבילה אינה כוללת:
- טפסים
- אנליטיקה
- פיקסלים
- קוקיז
- תלות ב-React, Node או Sites
